┌─────────────────────────────────────────────────────────────────────────────┐
│                       AUTHENTICATION FLOWS                                  │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌────────────────────────────────────────────────────────────────────┐
    │ LOGIN FLOW                                                          │
    └────────────────────────────────────────────────────────────────────┘

    Client → POST /api/auth/login
         │
         ▼
    AuthController.login()
         │
         ▼
    AuthService.login()
         │
         ├──→ AuthenticationManager.authenticate()
         ├──→ InMemoryUserAccountRepository.findByUsername()
         ├──→ BCryptPasswordEncoder.matches()
         ├──→ JwtTokenProvider.generateToken() → Access Token (2h)
         └──→ RefreshTokenService.generateRefreshToken() → Refresh Token (7d)
         │
         ▼
    Returns LoginResponse (accessToken + refreshToken)

    ┌────────────────────────────────────────────────────────────────────┐
    │ REFRESH TOKEN FLOW                                                  │
    └────────────────────────────────────────────────────────────────────┘

    Client → POST /api/auth/refresh (with refreshToken)
         │
         ▼
    AuthController.refreshToken()
         │
         ▼
    AuthService.refreshToken()
         │
         ├──→ RefreshTokenService.validateRefreshToken() → username
         ├──→ UserDetailsService.loadUserByUsername()
         └──→ JwtTokenProvider.generateToken() → New Access Token
         │
         ▼
    Returns LoginResponse (new accessToken + same refreshToken)

    ┌────────────────────────────────────────────────────────────────────┐
    │ LOGOUT FLOW                                                         │
    └────────────────────────────────────────────────────────────────────┘

    Client → POST /api/auth/logout (Authorization: Bearer token)
         │
         ▼
    JwtAuthenticationFilter
         │
         ├──→ JwtTokenProvider.validateToken()
         └──→ TokenBlacklistService.isTokenBlacklisted() → false
         │
         ▼
    AuthController.logout()
         │
         ▼
    AuthService.logout()
         │
         ├──→ TokenBlacklistService.blacklistToken() → Blacklist access token
         └──→ RefreshTokenService.revokeRefreshToken() → Revoke refresh token
         │
         ▼
    Returns 204 No Content

    ┌────────────────────────────────────────────────────────────────────┐
    │ TOKEN VALIDATION FLOW                                               │
    └────────────────────────────────────────────────────────────────────┘

    Request with Authorization header
         │
         ▼
    JwtAuthenticationFilter.resolveToken()
         │
         ▼
    JwtTokenProvider.validateToken()
         │
         ├──→ TokenBlacklistService.isTokenBlacklisted() → Check blacklist
         │
         ├──→ If blacklisted → Return false (reject)
         │
         └──→ If not blacklisted → Validate JWT signature & expiration
              │
              ├──→ If valid → Set SecurityContext authentication
              └──→ If invalid → Return false (reject)

┌─────────────────────────────────────────────────────────────────────────────┐
│                          FLOW SUMMARY                                       │
└─────────────────────────────────────────────────────────────────────────────┘

    1. application.yml → Spring Boot → DataSource Bean
    2. DataSource → Flowable Starter → ProcessEngine
    3. ProcessEngine → Creates ACT_* tables in H2
    4. API Request → Controller → Service → Flowable Service
    5. Flowable Service → DataSource → H2 Database
    6. Results ← H2 ← DataSource ← Flowable Service ← Service ← Controller
    
    AUTHENTICATION FLOWS:
    7. Login → Generate Access Token (2h) + Refresh Token (7d)
    8. Refresh → Validate Refresh Token → Generate New Access Token
    9. Logout → Blacklist Access Token + Revoke Refresh Token
    10. Validation → Check Blacklist → Validate Signature → Set Security Context
